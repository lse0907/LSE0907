# LSE0907 Workspace

This repository contains the `qr-cafe-mvp` Next.js project.

## Quick start

```bash
cd qr-cafe-mvp
npm install
npm run dev
```

Then open <http://localhost:3000>.

## Project structure

- `qr-cafe-mvp/`: main web application.
- `qr-cafe-mvp/docs/`: planning notes and implementation checklists.
