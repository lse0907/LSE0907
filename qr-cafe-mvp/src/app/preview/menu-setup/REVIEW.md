# 메뉴 설정 미리보기 재점검

## 원본 대조·의심 항목 보완 (2026-10-19)

- 메뉴/옵션 수정에서 원본 사진과 설정을 동시에 표시. 넓은 화면은 2열, 모바일은 접을 수 있는 원본 상단 + 수정 영역 + 고정 적용 버튼.
- 여러 원본 중 해당 사진을 직접 선택하고 확대. 자동 사진/행 매칭 또는 자동 OCR 검증으로 표시하지 않음.
- 사진은 메모리만 사용하며 새로고침 후 재첨부. 사진 첨부 자체로 초안/기존 수정/실제 DB를 덮어쓰지 않음.
- 같은 카테고리의 선택된 중복 메뉴명을 필수 확인에 포함. 이름 수정/보류로 해소하거나 실제 별도 메뉴임을 명시 확인.
- AI 사이즈 그룹은 연결 메뉴 묶음 단위로 원본 대조 확인. 메뉴별 수정으로 잘못된 연결을 해제할 수 있음.
- 확인은 현재 메뉴명/가격/연결/그룹 조건의 지문과 함께 저장. 관련 내용 변경 시 무효화하며 새 최종 승인 필요.
- 연결 메뉴 목록은 6개씩 표시. 모든 메뉴에 별도 승인 체크를 붙이지 않음.
- 원본이 없는 상태나 그럴듯한 오탈자/잘못된 숫자의 자동 감지는 보장하지 않음. 기본 화면에 원본의 이름·가격 확인 필요를 안내.
- 개발 도구의 `원본 대조 가상 예시`: 4개 가상 메뉴·코드로 만든 가상 메뉴판. 실제 AI 결과나 사용자의 실사진을 변경한 결과가 아님.
  이 가상 원본은 외부 분석 입력에서 제외.
- 가상 화면 검증: 중복 이름 수정으로 확인 3→1건, 단일 사이즈 메뉴의 연결 해제, 이름 오탈자 수동 수정,
  그룹 범위 확인 후 0건, 최종 승인 체크 전 등록 예시 버튼 비활성 확인.
- 390×844 원본 표시/접기·하단 버튼 위치 및 기본 넓은 화면의 동시 대조 확인. 실기기 키보드/카메라는 미검증.
- localhost 별도 저장 공간에서 검사해 127.0.0.1에 저장된 기존 60개 초안은 수정하지 않음.
- 이번 보완에서 추가 API/DB 호출, 실제 메뉴 등록 및 운영 배포 없음.

## 실제 다중 사진 점검 (2026-10-19)

- 사진 2장 서버 검증 2회. 브라우저 파일 첨부 연결 오류로 서버 직접 실행했으므로 이미지 UI 종단 검증은 미완료.
- 사이즈 판매가/추가금 혼동과 한 행 누락을 발견해 지침 보완. 2차는 59개 메뉴/EXTRA 5개를 추출했다.
- 여전히 메뉴명 오인식과 빈 J/K 칸에 사이즈를 연결한 문제가 남아 있어 품질 통과 처리하지 않았다.
- 실제 등록/초안 적용은 하지 않음. 원본 행 근거 대조 및 가용성 검증이 다음 보완점.
- 승인된 임시 일일 제한은 원래 1회로 복구. 월 3회 및 플랫폼 비용 한도는 그대로 유지.

## 최신 실제 연결 검증 (2026-10-19)

- owner 로그인된 testximen에서 실제 CSV 2개 메뉴 분석 성공. 사용 원장 succeeded 1건 / $0.004978.
- 메뉴명/가격/분류/HOT·ICE 연결 확인. 명시되지 않은 옵션 조건/추가금은 확인 대상으로 유지.
- 결과는 미적용 후보로 저장. 기존 60개 예시 초안 및 실제 메뉴 데이터는 변경하지 않음.
- 추가 예약의 일일 제한 차단을 rollback 테스트로 검증. 로컬 호출 플래그는 다시 false.
- 아래 기록의 연결 대기/미검증은 해당 단계 당시 상태다. 실제 이미지/복잡한 자료와 관리자 등록은 아직 남아 있음.

## 재분석 안전 확인

- 성공 응답은 별도의 미적용 결과로 보관. 기존 초안/수정 내용/최종 승인 상태는 자동 변경하지 않음.
- 동일한 메뉴명·카테고리명을 기준으로 가격과 연결 옵션 내용 비교. 새 AI 식별자만 달라진 것은 변경으로 보지 않음.
- 동일 이름이 중복되면 자동 짝짓기/병합하지 않고 '이름 중복'으로 분리 표시.
- 이름이나 분류가 바뀌면 추가/빠짐으로 표시될 수 있으며, 자동 병합하지 않음.
- 적용 전 기존 초안 대신 새 결과 사용을 확인. 실제 DB 등록과는 별도이며 적용 후에도 최종 승인 필요.
- 미적용 결과는 기존 초안과 별도 브라우저 키로 보관, 닫기/새로고침 후 재확인 가능. 동의 상태는 보관하지 않음.
- 원본 자료가 없는 상태에서 원본 보기로 들어갔을 때만 재첨부 안내.
- 자동 검사: 가격 변경/추가/빠짐, 공유 옵션 변경 영향, ID 변경 무시, 동명이름 자동 매칭 금지.
- 실제 제공자 호출은 여전히 설정 대기. 가상 비교 예시는 외부 API 호출/DB 변경 없이 검증.
- 화면 검증: 새로고침 후 후보 복원/확인 체크 초기화, 기존 초안 유지, 3,000→3,500원 명시 적용 후 되돌리기로 3,000원 복구.
- 적용할 초안의 기기 저장에 실패하면 후보를 지우지 않고 기존 초안도 유지.

## 사용자 화면 간소화

- 기본 화면: 짧은 제목/한 줄 안내, 이미지·촬영·CSV, 첨부 목록, 초안 만들기.
- 개발 설명/가상 예시/상세 도움말은 기본 접힘. 매장 ID는 URL 또는 관리자 선택 정보를 우선 사용.
- 전송 동의와 기존 초안 교체는 초안 만들기 클릭 후 표시. 클릭만으로 외부 요청하지 않음.
- 매장 정보가 없으면 확인 단계에서 안내. 개발용 수동 입력은 접힌 개발 설정에만 제공.
- 390×844에서 첨부 CSV 1개를 포함한 기본 작업 화면이 세로 스크롤 없이 표시됨.
- 이는 미리보기 UI 변경이며 실제 관리자 마법사나 운영 설정은 변경하지 않음.

## AI 연결 코드 추가 (2026-10-19)

- 개발 전용 API/전송 동의/구조화된 응답 검증/실패 시 초안 유지 추가.
- 실제 호출은 키, 서버 플래그, owner 권한, 기존 사용 예약 정책이 모두 통과해야 함.
- 현 시점 실제 제공자 호출은 미검증이며 DB menu_setup 허용 목록도 후속 검토 필요.
- 자세한 준비 항목: `docs/menu-setup-ai-readiness.md` (저장소 앱 루트 기준).
- 아래 과거 점검의 'AI 미연결'은 해당 시점 기준이며, 현재도 실제 메뉴 DB 등록은 미연결.

## 통합 초기설정 방향 (2026-10-19)

- 실제 `/admin/setup`는 manual/copy/bulk 선택 후 카테고리 → 옵션 → 메뉴 → 옵션 연결 → QR의 5단계.
- `/admin/import`는 category_name/menu_name/price 등 정해진 CSV 컬럼을 사용. 타 서비스 파일의 자유 형식을 AI가 이해하는 기능과는 다름.
- 이번 수정은 개발 미리보기의 입구만 통합: 이미지 선택 / 직접 촬영 / CSV 첨부 → 동일한 초안 확인 화면.
- 이미지와 CSV 혼합·추가 첨부 가능. CSV는 이름/내용 일부/문자 인코딩을 로컬에서 확인하며 양식 변환을 요구하지 않음.
- 파일 첨부는 실제 동작하나 AI 분석/열 추론/메뉴 생성은 아직 없음. 첨부 자료와 무관한 공통 예시임을 명시.
- 사진과 CSV 원본은 메모리에만 보관, 새로고침 시 다시 첨부. 초안 저장과 별개.
- 검증: 임의 한글 헤더 CSV 파일 첨부/내용 확인/복원한 공통 초안의 자료 패널에서 유지.
  UTF-8 BOM/EUC-KR/UTF-16 디코딩과 파일 확장자·크기·빈 파일은 자동 검사.
  390px 모바일에서 가로 넘침 없음. 실기기 카메라 동작은 별도 확인 필요.
- 실제 마법사/CSV/템플릿/관리자 메뉴는 변경하지 않음. 매장 복사 경로도 유지할 계획.
- 추후 AI 승인 등록이 성공한 뒤 실제 저장 결과로 기존 단계 확인 조건을 충족하고 QR 확인으로 이동.
  미리보기 승인으로 setup_completed/단계 확인 플래그를 변경하지 말 것.
- 템플릿은 직접 입력/초안 보완에서 필요한 경우만 노출. 사진은 등록 후 기존 메뉴 관리에서 추가.

## 현재 범위

- 개발 전용 가상 메뉴 60개. 실제 AI 분석·관리자 DB 등록은 아직 연결하지 않음.
- 메뉴/카테고리/옵션 수정, 옵션 묶음 연결, 필수 확인 순서, 주문 금액 예시, 최종 승인 흐름.
- 이 브라우저 localStorage에 초안과 적용 전 메뉴/카테고리/옵션 편집 내용 저장.
- 새로고침 후 사용자가 이어하기를 선택하면 복원. 승인 여부/등록 결과는 복원하지 않음.
- 원본 사진, 되돌리기 이력, 묶음 연결 대상 선택, 검색/페이지 위치는 저장하지 않음.
- 사진 추가는 재분석이 아니며 초안을 변경하지 않음. 실제 재분석 병합 정책은 미구현.
