# AI 브리핑 제한 운영 기록

이 문서는 실제 AI 브리핑을 한 매장부터 안전하게 시작할 때의 실행 절차다. 전체 진행 상태는 [AI 현재 운영 체크리스트](./ai-current-operation-checklist.md)를 우선한다.

## 현재 기본 상태

- 전역 AI 사용: 중지
- OpenAI 월 경고 / 절대 상한: `$40 / $50`
- 정기 실행: 매일 03:20 KST (월요일은 주간, 매월 1일은 월간도 함께 생성)
- 화면 조회·브리핑 이력 조회·수동 스냅샷 저장: OpenAI 호출 없음, 비용 없음
- 실제 호출 대상: AI 사용 허용 상태의 매장 중 주문 200건 이상인 매장
- 전송 데이터: 매장별 기간·주문 건수·매출 합계만. 고객·결제·주문 원문은 전송하지 않음
- AI는 메뉴·가격·쿠폰·주문·환불·권한·코드·DB를 직접 변경하지 않음

## 제한 운영을 시작할 때

1. OPS에서 전역 AI 사용을 허용한다. 변경 사유와 월 경고/절대 상한을 확인한다.
2. 실제 대상 매장 **한 곳만** AI 사용 매장으로 설정한다. 다른 매장은 미설정 또는 일시 중지 상태를 유지한다.
3. 해당 매장이 주문 200건 이상인지 확인한다. 미만이면 데이터 수집 안내만 생성되고 OpenAI는 호출하지 않는다.
4. `AI_EXTERNAL_CALLS_ENABLED=true`를 Production에 설정하고 새 배포를 완료한다.
5. 다음 03:20 KST 실행 뒤 OPS 장부에서 호출 1건, 실제 비용, 결과 상태를 확인한다.
6. 점주 화면에서 사실·추정·제안의 구분, 근거 수치, 브리핑 이력과 평가 동작을 확인한다.
7. 문제가 있으면 OPS에서 전역 AI 또는 해당 매장을 즉시 중지한다. 다음 실행부터 새 호출은 차단된다.

## 반드시 확인할 결과

- 장부에 `daily_brief` / `weekly_brief` / `monthly_brief` 중 해당 실행만 남는다.
- 사실 문장은 서버가 저장한 집계만 사용한다.
- AI 응답 실패·시간 초과·한도 초과가 발생해도 집계 기반 브리핑은 저장되고 주문·결제 흐름에는 영향이 없다.
- 점주가 브리핑을 읽고 평가할 수 있으며, OPS에서 비용·오류·중지·변경 이력을 확인할 수 있다.

## 아직 하지 않는 것

- 여러 매장 동시 활성화
- 점주 버튼으로 즉시 AI 재생성
- AI의 자동 운영 변경
- 고객 개인정보·결제 정보·주문 원문 전송

## 완료 기준

한 매장에서 일간 브리핑 1회 이상을 확인하고, 비용·이력·점주 화면·즉시 중지를 모두 검증한 뒤에만 대상 확대를 논의한다.
