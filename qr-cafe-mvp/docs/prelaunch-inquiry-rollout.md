# 사전 이용 문의 전환

## 변경 범위
- 공개 `/owner` CTA와 `/beta-apply` 폼을 문의 흐름으로 전환. 기존 URL·조회 집계 유지.
- 필수: 매장명, 업종, 선택한 이메일 또는 문자 수신 휴대폰. 문의 내용은 선택.
- 선택하지 않은 연락처는 서버에서도 저장하지 않음.
- 문의 전용 개인정보 동의 버전·문서 추가. 과거 신청의 동의 문서는 그대로 유지.
- 기존 OPS·차수·접수 상태·기록 유지. 동의 버전으로 문의/기존 신청을 구분.
- 자동 문자·이메일 또는 전화 발송은 구현하지 않음. 운영자가 접수 연락처로 안내.

## 운영 반영 순서
1. `supabase/migrations/20261013071133_prelaunch_inquiry_optional_details.sql`을 대상 DB에 먼저 적용. **2026-10-13 적용 완료.**
2. 실제 DB에서 문의용 null 항목 및 기존 기록·RLS/서버 전용 권한을 검증. **검증 완료.**
3. 프론트/API 배포 후 이메일·문자 접수와 OPS 노출을 통제된 테스트로 확인.
4. 기존 OPS 공개 안내에 신청·선정 문구가 남아 있다면 운영자가 문의 안내로 수정. 이 작업은 기존 운영 데이터를 자동 변경하지 않음.

필수였던 지역·운영 방식·연락받을 분 이름·시작 시점을 문의에서 수집하지 않으므로 DB 호환 변경을 먼저 적용해야 합니다. 적용 전에는 새 문의의 실제 저장이 실패할 수 있습니다. 기존 신청 경로는 서버 검증을 유지합니다.
