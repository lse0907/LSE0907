# P1-2 구독·추천 혜택 확정안

## 베타 테스터 혜택

- OPS가 베타 테스터 자격과 혜택 매장을 직접 승인한다.
- 대표자당 첫 혜택 매장 1곳에만 적용한다.
- 기본 베타 참여 매장은 기본 구독 정상가격의 40%를 지속 할인한다.
- 온라인 선결제 추가 베타 참여 매장은 같은 혜택 매장의 온라인 선결제 옵션도 정상가격의 40%를 지속 할인한다.
- 기본 구독과 옵션의 참여·승인 상태를 분리해 기록한다.
- 베타 할인과 장기·추가 매장 가격할인은 중복하지 않는다.
- 할인율은 고정 금액이 아니라 결제 시점 정상가격에 적용한다.
- 구독 중단, 기간 만료, 재구독 또는 결제 실패만으로 베타 자격을 제거하지 않는다.
- 추가 매장, 계정 양도 또는 매장 양수인에게 자동 승계하지 않는다.
- 과거 결제에 소급 적용하거나 소급 환불하지 않는다.
- OPS 변경은 처리자, 시각, 사유와 변경 전·후 값을 감사기록에 남긴다.

## 일반 무료체험

- 신규 점주의 첫 번째 매장 기본 구독에 30일을 제공한다.
- 옵션에는 자동 무료체험을 제공하지 않는다.
- 동일 결제계정·동일 사업자·동일 대표자·동일 실질 운영주체의 반복 체험을 방지한다.
- 베타 혜택과 일반 무료체험을 중복 적용하지 않는다.
- 종료 후 자동 결제하지 않는다.

## 추천 혜택

- 매장별 추천코드는 내부 매장 ID와 분리한다.
- 신규 점주 가입 시 추천코드는 선택 입력이다.
- 하나의 신규 계정은 하나의 추천 매장과만 연결한다.
- 추천받은 신규 매장의 첫 기본 유료 구독에 3,000원 가격할인을 1회 적용한다.
- 추천한 매장에는 적격 결제 후 14일이 지나면 3,000원 기본 구독 전용 크레딧을 적립한다.
- 실제 외부 기본 구독 결제액이 1원 이상이어야 추천인 보상을 확정한다.
- 크레딧은 기본 구독료에만 사용하며 옵션료·현금·계좌환급·양도에는 사용할 수 없다.
- 가격할인 적용 후 크레딧을 사용하며 먼저 적립된 크레딧부터 사용한다.
- 크레딧으로 기본 구독료가 0원이 되면 PG 결제창 없이 서버에서 원자적으로 처리한다.
- 모든 적립·예약·사용·복원·회수·소멸·관리자 조정을 불변 원장에 기록한다.

## 적용 순서

1. 정상 기본 구독료
2. 베타·장기·추가 매장 가격할인
3. 신규 추천 3,000원 가격할인
4. 추천 크레딧
5. 옵션료 별도 계산
6. 실제 외부 결제액 확정

## 환불

- 가격할인은 복원하지 않는다.
- 외부 결제분은 원 결제수단으로 환불한다.
- 크레딧 사용분은 미사용기간 비율에 따라 크레딧 원장으로 복원한다.
- 14일 전에 전액 취소되면 추천인 보상을 확정하지 않는다.
- 14일 후 정상 확정된 보상은 통상적인 중도해지·부분환불만으로 자동 회수하지 않는다.
- 부정 추천·차지백·중복 지급·운영 오류는 OPS 근거 기록 후 회수할 수 있다.

## 용어 호환

기존 코드와 DB의 `founder_*` 필드는 무중단 마이그레이션을 위해 당분간 유지한다. 사용자 화면과 OPS에서는 `베타 테스터 혜택`으로 표시하고, 신규 로직은 기본 베타 참여와 온라인 선결제 베타 참여를 분리해 해석한다.
