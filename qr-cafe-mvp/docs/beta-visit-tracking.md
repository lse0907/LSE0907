# 신청 페이지 조회·신청 수
- OPS → 점주·매장 → 베타 신청의 현재 모집 상자에 조회 N회 · 신청 N건만 표시한다. 출처별 통계, 기간 필터, 별도 통계 상자는 없다.
- 조회는 /beta-apply 도착 시 서버가 현재 공개 차수에 기록한다. 같은 탭 30분 내 새로고침은 차수별 UUID 기본 키로 중복 제외한다. 고유 사람 수가 아니다.
- 신청 수는 해당 차수의 전체 접수 건수다. 검토 결과 상태와 무관하게 집계한다. 방문과 신청의 개인별 연결·전환 분석은 하지 않는다.
- UTM, IP, 연락처, 전체 URL, referrer를 수집·저장하지 않는다. 추적 매개변수 없이 사용한다.
- 개발 서버, localPreview, 일부 자동 봇은 제외한다. 완벽한 봇 판별은 아니므로 참고 지표이며 저장소 차단 시 중복 제외가 제한된다.
- docs/sql/supabase-beta-page-visits.sql은 아직 적용하지 않은 배포 초안이다. 기존 방문 테이블을 이미 적용했다면 그대로 재실행하지 말고 별도 호환 마이그레이션을 준비한다.
- 브라우저 DB 접근은 차단하고 서버 service_role만 기록/집계한다. OPS master/support만 조회한다. 조회 실패는 0 대신 —로 표시하고 신청 기능을 막지 않는다.
- 설치 이후 기록부터 조회 집계한다. 이전 방문은 복원되지 않는다. 현재 모집 상자 숫자는 60초마다 갱신된다.
- 배포 시 실제 방문 → OPS 조회 증가 → 새로고침 중복 제외 → 접수 신청 수 → 차수 간 분리 → 비로그인 OPS 거부를 확인한다. 로컬 숫자는 디자인 예시일 뿐 실측이 아니다.
