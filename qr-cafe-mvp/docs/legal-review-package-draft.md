# RION Order 법률 자문용 정책 패키지 초안

상태: **법률 검토 전 초안 · 이용자 공개 또는 법률 결론으로 사용 금지**
기준일: **2026-09-17**

## 1. 자문 목적

RION Labs가 운영하는 RION Order의 현재 구현과 예정된 운영 방식이 약관, 개인정보 처리방침, 동의 화면 및 고객 고지에 적절히 반영되었는지 검토받기 위한 자료다.

이 문서는 법률 자문을 대체하지 않는다. 자문 결과에 따라 이용약관, 개인정보 처리방침, 마케팅 안내 및 내부 보존 기준의 문구·운영 절차를 최종 확정한다.

## 2. 현재 서비스 구조

### 2.1 이용자와 서비스

| 구분 | 현재 제공 기능 | 계약·운영상 확인할 점 |
| --- | --- | --- |
| 고객 | 매장 메뉴 확인, 주문, 결제, 주문 상태 확인, 선택적 계정·혜택 이용 | 고객 주문 거래에서 판매자·결제 주체의 표시와 책임 분리 |
| 점주 | 매장 생성·관리, 메뉴·주문 운영, 구독 결제, 고객지원 요청 | RION Labs와 점주 사이의 B2B 구독 계약 및 고객정보 처리 관계 |
| 직원 | 점주의 권한 아래 주문 접수·제조·준비·전달 처리 | 업무용 계정·권한·감사기록의 처리 근거 |
| RION Labs | 주문·매장 운영 소프트웨어, 점주 구독, 고객/점주 지원, OPS 운영 | 플랫폼 운영자 역할과 책임 범위 |

### 2.2 결제와 정산 전제

- 고객 음식 주문의 결제는 해당 점주가 연결·계약한 POS 또는 PG를 통해 처리한다.
- RION Labs는 고객 주문대금을 수령·보관·정산하는 구조가 아니다.
- RION Labs는 점주에게 소프트웨어 구독 서비스를 제공하고 그 구독료를 별도로 청구할 수 있다.
- 위 전제가 실제 PG 계약서, 결제 화면의 판매자 표시, 정산 흐름과 일치하는지 확인한다.

## 3. 개인정보 처리 사실관계

### 3.1 현재 처리 범위

| 대상 | 현재 처리 정보의 예 | 목적 |
| --- | --- | --- |
| 고객 | 계정 정보, 선택 전화번호, 주문·혜택 이용기록 | 주문·계정·혜택 기능 제공, 고객지원, 보안 |
| 비회원 주문자 | 주문 처리에 필요한 주문정보와 필요한 경우 주문별 연락처 | 주문 이행과 주문 상태 안내 |
| 점주 | 계정, 사업자·매장 정보, 구독·결제·운영기록 | 매장 운영 도구·구독·고객지원 제공 |
| 직원·매니저 | 업무용 식별정보, 권한·감사기록 | 주문 운영 및 권한 관리 |
| 문의 첨부 | 점주가 선택해 올린 오류 캡처·사진 | 장애·문의 확인, 접근 권한 있는 OPS 검토 |

### 3.2 현재 안전 기준

- 선택 전화번호와 마케팅 동의는 분리하며, 주문 연락처를 회원 프로필이나 광고 대상에 자동 전환하지 않는다.
- 고객·점주·직원 권한을 분리하고, OPS 조치에는 이력을 남긴다.
- 문의 첨부는 공개 URL을 만들지 않으며, 초기 기준은 이미지 3개·각 5MB 이하·90일 후 원본 삭제다.
- 탈퇴·삭제 요청은 구독·결제·거래·동의 증빙 등 법적 보존 대상과 분리하여 처리한다.

## 4. AI 기능의 사실관계

- AI는 점주 브리핑, 문의 분류·안내, OPS 조치안 초안, 장애 분석 근거 정리에 한정한다.
- AI는 메뉴, 가격, 쿠폰, 포인트, 주문, 결제, 환불, 권한, 코드, 데이터베이스를 자동 변경하지 않는다.
- 실제 브리핑 외부 호출에는 매장별 기간, 주문 건수, 매출 합계만 사용한다. 고객 식별정보, 결제정보, 주문 원문은 전송하지 않는다.
- 외부 제공사는 초기 OpenAI API 한 곳이며, 서버 전용 키·호출별 장부·매장/전역 중지·월 $40 자동 중지 및 $50 절대 상한으로 통제한다.
- 현재 외부 AI 호출은 비활성화 상태다. 주문 200건 이상인 매장 1곳이 생기고 별도 승인할 때에만 제한 운영을 시작한다.

## 5. 현재 약관·동의 화면 상태

| 문서·화면 | 현재 상태 | 자문 요청 |

| 고객 이용정책 | 필수 동의 구조 존재 | 판매자 표시, 주문·취소·환불 책임과 고객 고지의 적정성 |
| 점주 B2B 이용정책 | 필수 동의 구조 존재 | 구독, 매장 책임, 고객정보 처리 관계, 해지·환불 기준 |
| 개인정보 처리방침 | 검토본 공개 | 처리 목적·항목별 근거·보유기간·위탁/제3자/국외 처리·문의처 확정 |
| 마케팅 정보 수신 안내 | 선택 동의, 서비스 알림과 분리 | 실제 이메일·문자·앱 푸시 발송 전 채널별 동의·철회·야간 발송 기준 |
| 문의 첨부 안내 | 개인정보 마스킹·제한 규칙 존재 | 첨부 보관·삭제 기준 및 안내 문구 |

## 6. 법률 전문가에게 확인할 질문

1. 고객 음식 주문에서 점주가 판매자·PG 계약·정산 주체이고 RION Labs가 소프트웨어 제공자일 때, 각 화면과 약관에 표시해야 할 거래 주체·책임·환불 안내는 무엇인가?
2. 점주에게 제공하는 유료 소프트웨어 구독 서비스의 약관, 청약·해지·환불 고지 및 전자문서 보관 방식은 적절한가?
3. 위 실제 결제·정산 구조를 전제로 통신판매업 신고 대상 또는 면제 여부를 최종 확인해 달라.
4. 고객, 비회원 주문자, 점주, 직원 정보별 처리 목적·법적 근거·최소 보유기간·파기 절차를 확정해 달라.
5. RION Labs와 점주 사이에서 고객 주문정보의 개인정보처리자, 공동처리자, 수탁자 또는 제3자 제공 관계를 어떻게 정리해야 하는가?
6. 외부 AI에 개인식별정보 없이 매장별 집계만 전달하는 현재 설계에서 개인정보 처리방침, 위탁 또는 국외 처리 고지가 필요한지와 필요한 문구를 확인해 달라.
7. 오류 캡처에 우발적으로 개인정보가 포함될 수 있는 경우, 업로드 안내·접근권한·보관기간·삭제 절차가 충분한가?
8. 마케팅을 실제 발송하기 전 이메일·문자·앱 푸시별 동의, 철회, 발송기록, 야간 발송 기준을 어떻게 확정해야 하는가?
9. 계정 탈퇴·개인정보 삭제 요청과 거래·결제·동의·보안 감사기록의 법정 보존을 어떤 기준으로 분리해야 하는가?

## 7. 자문 시 함께 제공할 자료

- 현재 고객·점주·직원 화면의 가입, 주문, 결제, 탈퇴, 마케팅 동의 흐름 캡처
- 현재 이용정책, 개인정보 처리방침 검토본, 마케팅 정보 수신 안내
- AI 고객지원·승인형 조치 운영 기준
- AI 현재 운영 체크리스트 및 AI 브리핑 제한 운영 기록
- PG 계약 주체·정산 주체·결제 화면 판매자 표시를 보여 주는 실제 또는 예시 자료
- 문의 첨부 접근권한·삭제 처리, 개인정보 요청·탈퇴 처리 흐름

## 8. 자문 전 변경하지 않는 원칙

- 기존 고객·점주 약관, 개인정보 안내, 마케팅 선택 동의의 UX를 이 문서만으로 변경하지 않는다.
- 외부 AI 호출을 법률 검토 이전에 자동 활성화하지 않는다.
- 법정 보존기간·국외 처리 여부·통신판매업 신고 여부를 코드나 이용자 문구에 임의로 확정하지 않는다.
- 자문 결과가 확정된 뒤에만 문서 버전, 시행일, 필요한 재동의 및 화면 고지 범위를 결정한다.
