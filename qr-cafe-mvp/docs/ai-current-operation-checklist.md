# RION Order AI 현재 운영 체크리스트

상태 기준일: **2026-09-17**
이 문서는 AI 기능의 현재 상태를 판단하는 단일 기준이다. 과거 설계 문서의 체크박스는 설계 당시의 요구사항이며, 현재 완료 여부는 이 문서를 우선한다.

## 운영 원칙

- AI는 브리핑·문의 안내·조치안 작성만 돕는다. 주문, 결제, 환불, 권한, 매장 설정, 코드, 데이터베이스를 자동으로 변경하지 않는다.
- 외부 호출에는 매장별 기간·주문 건수·매출 합계만 전달한다. 고객·결제·주문 원문은 전달하지 않는다.
- 플랫폼 월 경고/자동 중지 기준은 **$40**, 절대 상한은 **$50**이다.
- 자동 실행은 매일 **03:20 KST**이며, 월요일에는 주간 브리핑, 매월 1일에는 월간 브리핑을 함께 생성한다.

## 보류된 실제 운영 단계

| 순서 | 시작 조건 | 실행 내용 | 상태 |
| --- | --- | --- | --- |
| 1 | 취소되지 않은 주문 200건 이상인 매장 1곳 | 해당 매장만 AI 사용 허용 | 보류 |
| 2 | 사용자 사전 승인 | Production `AI_EXTERNAL_CALLS_ENABLED=true` 설정 및 배포 | 보류 |
| 3 | 다음 03:20 KST 실행 | 일간 브리핑 1회, 장부·비용·점주 화면·평가·즉시 중지 확인 | 보류 |
| 4 | 1~3 정상 확인 | 제한 매장 확대 여부 검토 | 보류 |

주문 200건 미만 매장은 데이터 수집 안내만 생성하며 OpenAI를 호출하지 않는다. 테스트 편의를 위해 이 기준을 낮추지 않는다.

## 계정·환경 상태

- `OPENAI_API_KEY`, `CRON_SECRET`, `AI_EXTERNAL_CALLS_ENABLED`는 Vercel Production 서버 환경변수에 등록되어 있다.
- 현재 외부 호출은 비활성화 상태로 유지한다.
- 현재 OpenAI 개발 계정은 `lse0907@gmail.com` 개인 개발 계정이다. 정식 공개 전에는 운영 전용 계정/소유권 이전 및 결제수단 정리를 다시 결정한다.
- 키·시크릿 값은 문서, 소스 코드, 채팅에 기록하거나 노출하지 않는다.
